# ScrTrans

覆盖在任意画面上的 Windows 屏幕实时翻译工具。框定一块区域，程序自动捕捉画面变化、识别文字，并把译文叠加回原来的位置。

> 本仓库**只提供编译好的免安装程序**，不包含源代码。

## 下载

前往 **[Releases 最新版](https://github.com/vely1314/Trans/releases/latest)**，下载 `ScrTrans.exe`（约 70 MB）。

双击即可运行 —— 不用解压、不用安装、不用装 .NET 运行时（运行时已打包在这一个文件里）。

> **首次运行可能弹出蓝色的「Windows 已保护你的电脑」**（SmartScreen）。这是未购买代码签名证书的程序都会遇到的提示，不是病毒。点 **「更多信息」→「仍要运行」** 即可。部分杀毒软件也可能误报，请自行判断。

| | |
|---|---|
| 系统 | Windows 10 2004（内部版本 19041）或更高 / Windows 11 |
| 架构 | 64 位 x64 |
| 其他 | 一个可用的大模型 API Key（见下节） |

## 第一次使用：必须自己填 API Key

**程序里不包含任何 API Key，也不会使用发布者的额度。** 首次启动时 Key 是空的；不填就点翻译只会提示「API 调用失败，请检查配置」，不会发出任何网络请求。

1. 点顶栏的 **设置** 按钮打开设置窗口
2. **厂商** 选择：`硅基流动 SiliconFlow` / `DeepSeek 深度求索` / `自定义模型 · OpenAI 兼容`
3. 在 **API Key** 里填**你自己申请**的 Key，选好模型，可点 **测试连通** 验证
4. **翻译引擎** 建议保持 `OCR 定位 + 文本翻译`（位置更准确）；需要端到端多模态可选另一项
5. 设置 **目标语言**、译文样式，点 **保存**
6. 回到主界面，拖右下角手柄框定要翻译的区域，开 **自动**，或点 **翻译** 只翻一次

> 还没有 Key？到硅基流动或 DeepSeek 官网注册账号即可，各用各的额度。选「自定义模型」可以填任何 OpenAI 兼容接口地址。

**Key 存哪**：Windows 凭据管理器，另有当前用户 DPAPI 加密的本地兜底副本。换一台电脑或换一个 Windows 账户都解不开。配置文件 `%AppData%\ScreenTrans\config.json` 是明文，但里面**只有窗口尺寸、语言、厂商等偏好，没有任何密钥**。

## 功能速览

| 入口 | 说明 |
|---|---|
| **自动** | 画面变化时才发请求，静帧不重复翻译、不重复扣费；默认最小触发间隔 1500 ms |
| **翻译** | 立即翻译一次，全局热键 `Ctrl+Shift+T` |
| **悬浮** | 切换置顶 / 普通窗口，全局热键 `Ctrl+Shift+F` |
| **对照** | 原文 / 译文对照显示 |
| **清空** | 只清掉屏幕上的译文，**不会取消正在进行的翻译任务** |
| **复制** | 底部面板右下角的小按钮，一键复制译文到剪贴板 |
| **设置** | 厂商、Key、模型、翻译引擎、目标语言、字体 / 描边 / 遮罩、透明度、开机自启 |
| **托盘** | 双击显示 / 隐藏窗口；右键可开关自动翻译、切换悬浮置顶、退出 |

## 隐私

- 截图与译文**不落盘**，程序关闭即清空
- 唯一的对外网络请求，是你自己配置的那个大模型 API 地址
- 程序不上传、不统计任何使用数据
